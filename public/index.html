교환 가능한 여유분 카드

보유 수량이 2개 이상인 구성품입니다. 내 완성분(1개)을 제외한 나머지를 교환에 활용할 수 있어요.

교환 관리 대시보드

담긴 카드가 없어요. "내가 줄 멤버/구성품"을 고르고 "담기"를 눌러주세요.
받을 구성품을 선택하면 예시 이미지가 표시돼요.

분철 발송 관리

담긴 구성품이 없어요. 위에서 멤버/버전을 고르고 "버전 전체 담기"를 누르거나, 구성품을 하나씩 담아보세요.

전체 발송 관리

한 사람에게 특정 멤버의 구성품 21개를 통째로 보낼 때 사용해요. 일부만 보낼 땐 "분철 발송" 탭을 이용하세요.
멤버를 선택해주세요.

초대 코드 관리

회원가입에는 초대 코드가 필요해요. 아래에서 코드를 발급해 결제/전달 후 공유해주세요. 코드는 1인 1회용이에요 (한 번 가입에 쓰이면 자동으로 사용 처리돼요).
