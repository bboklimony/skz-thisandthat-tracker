# STRAY KIDS THIS&THAT 구성품 트래커 (인터넷 배포용)

이 폴더는 대시보드를 **진짜 인터넷 주소**에서 열고, 상태 변경이 **자동으로 클라우드에 저장**되도록 만든 프로젝트예요. 아래 순서를 그대로 따라오시면 됩니다. 한 번도 안 해봤어도 전부 브라우저 클릭만으로 끝나요 (터미널/코딩 필요 없음).

예상 소요 시간: 10~15분

---

## 0단계. 준비물

- GitHub 계정 (없으면 https://github.com/signup 에서 이메일로 무료 가입, 1분)
- Vercel 계정 (이미 회사에서 쓰고 계신 것으로 보여요 — retentionmathflat.vercel.app. 같은 계정으로 로그인하면 됨. 없으면 https://vercel.com/signup 에서 "Continue with GitHub"로 가입하는 게 제일 빠름)

---

## 1단계. GitHub에 이 폴더 올리기 (터미널 없이, 웹에서)

1. https://github.com/new 접속
2. Repository name에 `skz-thisandthat-tracker` 같은 이름 입력 → Public 또는 Private 아무거나 선택 → **Create repository**
3. 생성된 저장소 페이지에서 **"uploading an existing file"** 링크 클릭
4. 이 프로젝트 폴더 안의 파일/폴더 전체를 그대로 끌어다(드래그 앤 드롭) 놓기
   - `api` 폴더, `public` 폴더, `package.json`, `.gitignore`, `README.md` 전부 포함해서 올려주세요
   - 폴더째로 끌어다 놓으면 GitHub가 알아서 하위 폴더 구조(`api/state.js`, `public/index.html`)를 유지해줘요
5. 아래 **Commit changes** 버튼 클릭 (초록 버튼)

이제 GitHub 저장소에 코드가 올라갔어요.

---

## 2단계. Vercel에 배포하기

1. https://vercel.com/new 접속 (Vercel 로그인 필요)
2. **Import Git Repository** 목록에서 방금 만든 `skz-thisandthat-tracker` 저장소를 찾아 **Import** 클릭
   - 목록에 안 보이면 "Adjust GitHub App Permissions"를 눌러서 방금 만든 저장소에 접근 권한을 줘야 해요
3. 프로젝트 설정 화면이 뜨면 별도 설정 변경 없이 그대로 **Deploy** 클릭
4. 1~2분 기다리면 배포 완료 화면과 함께 `https://skz-thisandthat-tracker-xxxx.vercel.app` 같은 실제 주소가 생겨요

지금 접속하면 대시보드는 뜨지만, 아직 저장소(데이터베이스)를 안 붙였기 때문에 상단에 "⚠ 클라우드 연결 실패"라고 떠요. 3단계에서 해결해요.

---

## 3단계. 자동 저장용 저장소(데이터베이스) 연결하기

1. 방금 만든 Vercel 프로젝트 화면에서 상단 탭 중 **Storage** 클릭
2. **Upstash** (Redis) 선택 → **Install** / **Connect** 진행
3. 무료 요금제(Free) 선택 → 이름/지역은 기본값 그대로 두고 생성
4. 생성 후 "이 프로젝트에 연결(Connect to Project)" 화면이 뜨면 방금 만든 `skz-thisandthat-tracker` 프로젝트를 선택해서 연결
   - 연결하면 Vercel이 필요한 접속 정보(환경변수)를 자동으로 프로젝트에 넣어줘요. 직접 입력할 값은 없어요.
5. 연결하면 Vercel이 프로젝트를 자동으로 다시 배포해요 (Deployments 탭에서 진행 상황 확인 가능). 안 되면 Deployments 탭에서 최신 배포 옆 **⋯ → Redeploy** 클릭

배포가 끝나면 아까 그 URL로 다시 접속해보세요. 상단 상태가 "✓ 저장됨" 또는 "새 데이터로 시작"으로 바뀌면 성공이에요.

---

## 4단계. 처음 접속 — 회원가입

배포 후 URL로 처음 들어가면 로그인/회원가입 화면이 떠요. **회원가입** 탭에서 닉네임(2~20자, 한글/영문/숫자)과 비밀번호(4자 이상)만 정하면 바로 시작돼요. 이메일은 필요 없어요.

- 각자 만든 계정(닉네임)마다 데이터가 완전히 분리돼서 저장돼요. 슬님이 만드신 닉네임으로 보유/교환 현황을 관리하고, 같이 쓰는 다른 분들은 본인 닉네임으로 회원가입하면 각자 자기 컬렉션만 보고 관리하게 돼요 — 데이터가 서로 섞이지 않아요.
- 비밀번호를 잊어버리면 복구 수단이 없어요(이메일을 안 받기 때문). 잊어버리면 새 닉네임으로 다시 가입해야 해요. 중요한 데이터라 걱정되면 닉네임/비밀번호를 메모해두는 걸 추천해요.
- 로그인 상태는 브라우저에 쿠키로 오래 유지돼서, 한 번 로그인해두면 다음에 같은 브라우저로 들어올 때 자동으로 로그인돼 있어요. 다른 기기에서는 그 기기에서 한 번 더 로그인(또는 회원가입)하면 돼요.

---

## 5단계. 확인

- 대시보드에서 구성품 상태를 하나 바꿔보고, 상단의 저장 상태가 "저장 중…" → "✓ 저장됨 · HH:MM"으로 바뀌는지 확인
- 다른 기기(휴대폰 등)에서 같은 주소로 접속해서 같은 계정으로 로그인해도 방금 바꾼 내용이 그대로 보이면 정상 작동하는 거예요

## 6단계. 이미지/PDF로 내보내기, 공유 링크

탭 바로 아래 "내보내기/공유" 줄에 4개 버튼이 있어요.

- **🖼️ 현재 화면 이미지로**: 지금 보고 있는 탭 하나만 PNG 이미지로 저장. 트위터/카톡에 바로 올리기 좋아요.
- **🗂️ 전체 페이지 이미지(ZIP)**: 개요·구성품 보드·멤버별 갤러리·여유분 카드·교환 관리·분철 발송·전체 발송 — 7개 탭을 전부 각각 이미지로 캡처해서 압축 파일(zip) 하나로 받아요.
- **📄 전체 페이지 PDF**: 위와 동일하게 7개 탭을 전부 캡처해서, 한 페이지씩 들어간 PDF 파일 하나로 받아요. 인쇄/문서 공유용으로 좋아요.
- **🔗 공유 링크**: 로그인 없이도 볼 수 있는 나만의 공개 링크를 만들어줘요. 이 링크를 받은 사람은 **개요 / 구성품 보드 / 멤버별 갤러리 / 여유분 카드**만 읽기 전용으로 볼 수 있어요(수정 불가, 그 안에서 이미지/PDF로도 내보낼 수 있음). 교환 관리·분철 발송·전체 발송에 적어둔 상대방 닉네임/연락처/운송장번호 같은 정보는 이 링크에 절대 포함되지 않아요.
  - 링크가 유출됐거나 더 이상 공유하고 싶지 않으면 "링크 재발급" 버튼으로 기존 링크를 즉시 무효화하고 새 링크를 받을 수 있어요.
